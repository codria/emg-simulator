# 実装決定ログ

`emg_robotarm_exhibit_design.md`（仕様 SSoT）の未確定事項に対し、実装で採用した決定を記録する。
背景・論拠は元 doc 参照。ここは「何に決めたか」の索引。

## 制御・マッピング
- **制御方式：位置制御**（§3.5）。transform を差し替え可能にし、将来 速度制御を足せる余地は残す。
- **EMG 正規化①（個人差吸収 / signal 層 / §5）**：脱力ベースライン減算 → スケール → tanh ソフト飽和
  → 上方向のみオンライン適応 → フォールバック固定ゲイン。**左右独立**。出力＝活性度 `a_L, a_R ∈ [0,1]`。
- **可動域正規化②（スケーリング / transform 層）**：
  - **左腕→θ（向き）／右腕→r（伸ばす）**。config で入替可（§3）。
  - 操作平面 **z=0（水平）**。`target = (r·cosθ, r·sinθ, 0)`。床は z<0 に描画。
  - z=0 の到達可能域は**環状帯 r∈[0.34, 0.64]**（腕は基部まで折り畳めない＝r_min>0 の必然、§3 の特異点回避と一致）。
    既定 **r∈[0.36, 0.60]／θ∈[0, π]**（帯の内側に余裕）。**到達扇形にクリップ**して IK 解なしを回避。すべて config。

## セッション / キャリブレーション（§5）
- 係員がキー押下 → 「力を抜いて」2秒でベースライン取得 → プレイ開始。交代も同キーでリセット。
- MVC（全力取得）は既定オフ。オンライン適応で追従。

## ゲーム（§4）
- 到達判定：`‖先端−目標‖ < 閾値` が連続 0.3〜0.5秒（config）。
- **5個到達 → タイム表示 → リセット**。無人時 **アトラクトモード**（ダミー入力で自走デモ）。
- 次目標は到達扇形内ランダム＋現在位置から一定距離以上離す。

## 目標マーカー（§5.5）
- 出す。形式＝**帯＋遅延フェードイン**。遅延度は config/スライダで調整。位置制御前提（速度制御時は自動 off）。
- 3D 側に距離リング等の手がかりを併置し、視線がバーに偏るのを緩和。

## 画面表示
