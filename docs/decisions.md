# 実装決定ログ

`emg_robotarm_exhibit_design.md`（仕様 SSoT）の未確定事項に対し、実装で採用した決定を記録する。
背景・論拠は元 doc 参照。ここは「何に決めたか」の索引。

## 制御・マッピング
- **制御方式：位置制御**（§3.5）。transform を差し替え可能にし、将来 速度制御を足せる余地は残す。
- **DSP 前段（§6 / signal 層）**：Butterworth 帯域通過(≈20–450Hz)＋メインズノッチ(50/60Hz) を
  RMS の前段に（streaming SOS, scipy）。**生波形表示はフィルタ前（"生"）、RMS はフィルタ後**。既定 ON、
  settings で調整可。ダミーは hum 無しなので影響小、実 EMG 用。
- **EMG 正規化①（個人差吸収 / signal 層 / §5）**：脱力ベースライン減算 → スケール → tanh ソフト飽和
  → 上方向のみオンライン適応 → フォールバック固定ゲイン。**左右独立**。出力＝活性度 `a_L, a_R ∈ [0,1]`。
- **可動域正規化②（スケーリング / transform 層）**：
  - **左腕→θ（向き）／右腕→r（伸ばす）**。config で入替可（§3）。
  - 操作平面 **z=0.045（肩＝Tube3 中心の高さ、水平）**。`target = (r·cosθ, r·sinθ, z)`。床は z<0 に描画。
  - **回転中心は基部でなく肩(J2, z≈0.045)**。水平到達は**肩の高さで最大**（実測 r=0.732）、上下どちらにずれても
    減衰（z=0.4 で 0.686）。＝操作平面を肩に置くのが到達最大。（以前の「上げると縮む/√(R²−z²)」は基部中心と誤認、訂正）
  - **可変肘バイアス**（elbow_target を near2.0/far0.1 で r に応じ補間, gain0.15）：近い＝畳む・遠い＝伸ばす。固定バイアスの
    ~0.29 内側制約は IK 実装都合で実アームは畳めば r≈0.02 まで届くため、可変化で**物理どおり r≈0.14〜0.73 の全域**を使用。既定 **r∈[0.15, 0.72]／θ∈[0, π]**。
  - **tool-down 副次タスク**：手先 approach 軸（末端 +Z）を world −Z へ向け、**マニピュレータが目標に対し下向き**に（低 r で完全に下）。null-space なので到達に影響しない。
  - **reach_full_activation=0.9**：ソフト飽和で満力の活性度が 1.0 未満(~tanh(sat_gain))になり満力でも r_max に届かない
    ので、満力＝全レンジになるよう再スケール（満力で腕が伸び切る。それ未満は滑らか）。

## セッション / キャリブレーション（§5）
- 係員がキー押下 → 「力を抜いて」2秒でベースライン取得 → プレイ開始。交代も同キーでリセット。
- MVC（全力取得）は既定オフ。オンライン適応で追従。

## ゲーム（§4）
- 到達判定：`‖先端−目標‖ < 閾値` が連続 0.3〜0.5秒（config）。
- **5個到達 → タイム表示 → リセット**。無人時 **アトラクトモード**（ダミー入力で自走デモ）。
- 次目標は到達扇形内ランダム（**面積一様**: `r=√(U[r_min², r_max²])`、θ 一様）＋現在位置から min_sep 以上離す。
  **アプリは毎回ランダム seed**（Engine 既定 seed=None）で目標列が毎回変わる。テストは明示 seed で決定的。

## 目標マーカー（§5.5）
- 出す。形式＝**帯＋遅延フェードイン**。遅延度は config/スライダで調整。位置制御前提（速度制御時は自動 off）。
- 3D 側に距離リング等の手がかりを併置し、視線がバーに偏るのを緩和。

## 画面表示
- 中央：3D（アーム/床/目標球）。両サイド：正規化後の**筋電位バー**（§5.5、目標マーカーはここ）。
- **湾曲アーム（§9 解決）**：C++ 描画はメッシュファイルではなく**パラメトリック生成**（`genCylinder` /
  3次ベジェ掃引 `genCurvedBone` / フランジ）。`emg_sim/ui/armmesh.py` に幾何生成器＋部品配置を移植し、
  各部品を `GLMeshItem`（transform = `Ts[parent+1] @ local_xform`）で描画。
- **波形：画面右側に2行（上＝右腕 "Right Arm EMG"・下＝左腕）。** 生波形（淡色）＋**正規化後の制御値=判定値**
  （明色の線, 0..1）を重畳。時間窓 3.5s（スクロール緩め）。バーは同じ制御値の現在値（数値）。
- バーと波形の配置整合など最終レイアウトは描画実装時に詰める。
- **配色（`ui/theme.py` で一元管理）**：R=水色 / L=黄 / 目標=緑（＝重要な色付き要素）。前方矢印・到達領域(扇)は
  **モノクロ**（白系/グレー）で盤面を落ち着かせる。アーム・先端=白。各概念に一意の色（バー・グラフ・3D で共通）。
- **極座標の可視化（教育用）**：**アーム先端に対して動的に** 半径線 r（**水色**＝R）＋角度弧 θ（**黄色**＝L、θ=0 基準線から）
  を描画（力むと伸縮して見える）。r/θ の色は R/L チャンネルと一致。バー上部は Left/Right（R と r の混同回避）。
